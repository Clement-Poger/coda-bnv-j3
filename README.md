# Exercices C - J3

Ce dépôt contient les exercices de programmation en C du module J3, organisés par dossier.

## Contenu

- `ex-1/` à `ex-5/` : programmes C correspondant à chaque exercice.
- Chaque dossier contient un fichier `main.c` ainsi qu’un binaire compilé associé.

## Utilisation

Pour exécuter un exercice, compilez le fichier `main.c` dans le dossier voulu :

```bash
cd ex-1
./ex-1
```

Remplacez `1` par le numéro de l’exercice souhaité.
